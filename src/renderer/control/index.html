使用提示

  • 选一块显示器 → 点「上屏」，大屏画面会全屏铺满那块屏。
  • 本窗口始终留在主屏，方便你边改边看；改动的每个字都会实时出现在大屏上。
  • 现场防干扰：可点「黑屏待机」临时隐去画面，撤屏前无需关软件。
  • 上屏期间软件会阻止该显示器休眠。
  • 快捷键：Ctrl+Alt+B 黑屏 · Ctrl+Alt+H 收起/唤出控制台 · Ctrl+Alt+S 上屏/撤屏。
  • 下次启动会自动回到这次上屏的那块屏；开机自启时同样生效，开机即出画面。

手机遥控

未开启

同一 Wi-Fi 下，手机浏览器打开下面地址，就能改动态、拖进度、改标题，改动实时上大屏。不用装 App。

启动推送接口后可用

现场网络人多时建议设个口令，手机第一次打开会要求输入。

HTTP 实时推送

未启动

让外部系统（脚本 / MES / 表格工具 / 网页）把任务数据实时推到大屏。局域网内任何机器都能推。

POST http://<本机IP>:7788/api/board
Content-Type: application/json

{
  "title": "施工动态总览",
  "rows": [
    {
      "team": "一号施工队",
      "act": "三层顶板钢筋绑扎",
      "prog": 72,
      "proc": "钢筋工程"
    }
  ]
}

# team / act / prog / proc 是列的 key（可在「列设置」里改）
# 只想改数据就传 rows；要改列结构再带上 columns
# GET /api/board 读取 · GET /api/health 健康检查

启动与托盘

常驻托盘：关掉窗口不会退出，大屏照常推送；点托盘图标随时唤回控制台。

开机后自动在托盘待命，不弹窗打扰。

数据与维护

—

每次启动自动留一份备份（半小时内不重复，最多 5 份），误改可从 backup 目录捞回来。

关于

Yuhox Board 是一款开源免费的实时屏幕数据动态显示软件：控制台在主屏编排，画面全屏推送到指定显示器。支持 HTTP 推送、文件监听与手动编辑三种实时数据方式。

项目地址：github.com/mxyg/yuhox-board（MIT License）
