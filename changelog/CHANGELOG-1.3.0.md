# 1.3.0

这一版把开箱数据和默认画面按现场实际报表重做了一遍。

## 默认数据：金宇建安小修作业

- 首次启动自带一份真实表结构：小队 / 原井号 / 施工项目 / 区域 / 施工进度 / 新井号 / 新施工项目 / 新区域 / 备注，18 条示例数据
- 去掉了「序号」列 —— 和小队编号并排出现两列数字太容易看混；需要自动编号时可在「列设置」里自己加回
- 输入历史（自动补全候选）预置了表里出现过的井号、项目、区域、状态，装完直接打字就有联想

## 大屏

- 默认版式改为**竖向列表**：一行一条，井号 + 项目/区域标签 + 右侧状态标签，一屏 10 条，其余自动滚动
- 列表行可以**直接拖动排序**：按住一行拖到目标位置松手即落库（拖动时自动暂停滚动），控制台与手机同步看到新顺序
- 自动滚动改成**首尾相连**：整段滚完接下一段时不再有半拍跳动（同时修掉了列表版式里滚动压根没启动的问题）
- 横向信息更密：16:9 画面下一行能同时看到小队、施工项目、区域、新井号、新施工项目、新区域、备注
- 新增状态文字识别：施工进度列写的是「完井 / 下泵管完 待校深 / 套铣未完」这类文字时，自动按「待办 / 进行 / 完成」分类并标色（黄 / 蓝 / 绿），不再依赖百分比
- 指标卡在没有百分比列时改为 施工项 / 进行中 / 已完成 / 完成率，完成率用环形图显示
- 表格版式上下边缘淡出，滚动时半截行不会硬切在表头和字幕条上
- 行首状态光条：完成的行变绿，其余跟随主题色

## 手机遥控

- 字段两列并排（短字段成对、长字段独占一行），一屏能改更多内容
- 卡片顶部显示井号和当前状态，颜色跟着状态走
- 底部新增状态快捷标签：按当前数据里最常用的 5 个状态生成，一点即填
- 状态标签、标题都做了防抖与断线重连，改一格只提交这一格

## 其它

- 控制台数据表在窄窗口下不再挤压成一行小字，列宽仍可拖拽调整
- 端到端测试改为复用软件已启动的推送端口（1.2.0 起接口随软件自启），不再固定 7798/7799
