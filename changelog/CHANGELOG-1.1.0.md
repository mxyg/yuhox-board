## 1.1.0 · 可变列数据表 + 托盘常驻

### 数据表完全自定义
- 列头双击改名，列可拖拽调序，鼠标按住列缝即可拖宽（控制台与大屏同步比例）
- 可新增列（文本 / 进度两种类型）、可删除列、可隐藏列
- 行支持拖拽调序，序号列自动重排
- 进度列输入 0–100，大屏自动画进度条并按完成度标色（未开工 / 进行中 / 已完成）

### 实时同步更稳
- 大屏渲染改为按行 id 差异化更新：只动变化的单元格，新增行有光晕、变更单元格闪一下、删行有退场动画
- 滚动改按时间推进，窗口被遮挡或节流时速度依旧恒定
- 编辑时抑制回声刷新，输入不会被打断

### Excel 与输入记忆
- 一键导出 Excel：表头、列序、列宽一并导出，进度写为带百分号的数字格式
- 导入 Excel / CSV：按表头自动匹配现有列，陌生表头自动新建列；支持覆盖或追加
- 填过的队伍、工序、动态自动记入输入历史，下次输入即刻联想（Excel 导入的内容同样进历史）

### 大屏视觉
- 新增流光光束、雷达环、扫描线、HUD 边角、漂浮光点、标题扫光等装饰动效
- 面板加深、背景收敛，长时间观看不刺眼、不发热
- 主标题、副标题随时可改，控制台顶部与大屏左侧两处输入框实时联动

### 常驻与开机自启
- 新增托盘图标：托盘菜单可直接显示控制台、切换上屏显示器、黑屏待机、撤下大屏、退出
- 关闭窗口不再退出程序，收进托盘继续推送大屏；托盘菜单「退出」才真正结束
- 新增「开机自动启动」开关，默认开启；开机后带 `--hidden` 静默启动，只在托盘待命，不弹窗
- 单实例运行：重复双击只会唤出已有窗口，不会启动第二份进程

### 其他
- 旧版 `tasks` 数据首次启动自动迁移为默认五列，内容不丢
- 大屏版式调整为「施工数据表」与「进度榜单」两种
