## 1.2.0 · 手机遥控 + 开机即出画面

### 手机遥控（新）
- 手机浏览器打开 `http://电脑IP:7788/m` 即可遥控：改施工动态、改队伍工序、加减进度、一键「完成」、改主副标题
- 大按钮、整列进度卡片，戴手套也能点；改动 350ms 内落到大屏，断线自动重连
- 可选访问口令（4–12 位），设了口令后手机首次打开需输入；口令为一次性共享码，不落库到手机以外的任何地方
- 控制台「实时数据源」页显示可直接照着念的地址，可一键复制 / 本机打开；托盘也留了入口
- 服务端新增单行局部更新 `rowPatch`，手机改一格只提交这一格，不会覆盖别处同时改的内容

### 开机即出画面
- 记住上次上屏的显示器，下次启动自动回到那块屏（可在设置里关）
- 开机自启时同样生效：开机后后台拉起大屏，控制台不弹窗，直接进托盘
- 显示器拔了 / 不在时自动跳过，不会把画面误推到主屏

### 全局快捷键
- `Ctrl + Alt + B` 黑屏 / 恢复画面
- `Ctrl + Alt + H` 收起 / 唤出控制台
- `Ctrl + Alt + S` 上屏 / 撤下大屏
- 被其它软件占用时自动跳过，控制台里能看到实际注册成功的是哪几个

### Windows 便利性
- 任务栏右键（JumpList）：显示控制台 / 直接上屏 / 仅托盘待命
- 推送接口随软件自动启动，装完就能用手机连，不用先去点「启动」
- 便携版数据存到 exe 同目录的 `YuhoxBoardData`，整个文件夹拷到另一台电脑即接着用
- 「数据与维护」卡片显示当前数据文件路径，可一键打开数据目录

### 数据安全
- 每次启动自动备份，半小时内不重复、最多留 5 份，误改误删可从 `backup` 目录捞回
- 新增「恢复示例数据」「清空所有数据」，都在确认后才执行

### 录入与显示
- 数据表里按回车直接跳到下一行同一列，連續录一整列不用摸鼠标；到最后一行回车自动加行
- 大屏新增字号缩放（80%–150%），远距离观看或高分屏可整体放大

### 工程
- 新增三套无需开窗口的测试：数据层（14 项）、HTTP 接口（13 项）、界面 id 引用一致性
- `npm test` 一次跑完；CI 出包前也会先跑测试
- 状态广播不再为几个开关深拷贝整份看板数据
