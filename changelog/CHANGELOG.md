# 更新日志

## 1.3.0

开箱数据与默认画面按现场报表重做。

- 默认数据换成《金宇建安小修作业》：小队 / 原井号 / 施工项目 / 区域 / 施工进度 / 新井号 / 新施工项目 / 新区域 / 备注，18 条
- 去掉多余「序号」列，避免和小队编号并排出现两列数字；需要时可在列设置里加回
- 大屏默认改为竖向列表，一行一条；状态列是文字时自动按「待办 / 进行 / 完成」标色
- 大屏列表可直接拖动行排序，拖动时暂停滚动；超出屏高自动首尾相连滚动
- 一行横向展示小队 / 项目 / 区域 / 新井号 / 新项目 / 新区域 / 备注，16:9 画面信息更密
- 指标卡改为 施工项 / 进行中 / 已完成 / 完成率（环形图）
- 手机遥控页字段两列紧凑排布，新增状态快捷标签，卡头显示井号与状态

## 1.2.0

手机遥控、开机即出画面、全局快捷键与 Windows 便利性。

- 手机浏览器打开 `http://电脑IP:7788/m` 就能改数据、拖进度、改标题，支持可选口令
- 记住上次上屏的显示器，启动（含开机自启）自动回到那块屏
- 全局快捷键：`Ctrl+Alt+B` 黑屏、`Ctrl+Alt+H` 控制台、`Ctrl+Alt+S` 上屏/撤屏
- 任务栏 JumpList（显示控制台 / 直接上屏 / 仅托盘待命）
- 推送接口随软件启动；便携版数据存 exe 同目录，换机拷贝即用
- 启动自动备份（最多 5 份）、导入 JSON 备份、恢复示例、清空数据
- 便携版开机自启与任务栏菜单指向真实 exe，数据随文件夹走
- 数据表回车跳下一行同列；大屏字号缩放 80%–150%
- 新增 `npm test`：数据层 / HTTP 接口 / 界面 id 一致性三套无窗口测试

## 1.1.0

数据表可变列、Excel 互通、托盘常驻与开机自启。

- 列头可改名、列可拖拽调序、拖列缝调宽，可增删列；行可拖拽调序；新增进度列
- 大屏按行差异化渲染，单元格变更闪烁、新行光晕；滚动按时间推进，被遮挡也不降速
- 导出 Excel（含表头与列宽）；导入 Excel / CSV 按表头自动匹配，陌生表头自动建列
- 输入历史自动补全，Excel 导入的值也进历史
- 大屏新增流光光束、雷达环、扫描线、HUD 边角等装饰；主副标题随时可改
- 新增托盘图标与「开机自动启动」开关（默认开）；关窗收进托盘、大屏继续推；单实例运行

## 1.0.0

首个开源版本。

- 控制台在主屏编辑，画面可钉到任意指定显示器全屏输出
- 实时数据三种来源：控制台手动编辑、HTTP 推送（`POST /api/board`）、JSON 文件监听
- 大屏两种版式：泳道看板、进度榜单
- 动态视觉：粒子与极光背景、标题渐变、KPI 数字滚动、进度条过渡、内容溢出自动循环滚动
- 现场能力：黑屏待机、显示器热插拔回落、上屏防熄屏、断网可用
- Windows 安装包（NSIS）与便携版
